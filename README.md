# Lily-AI
A local AI assistant with a VRM avatar. *Beware!!! This is AI-generated work and only created as a hobby and personal project by non-expert. Listens through your mic, thinks with a local LLM (Ollama, Qwen2.5), speaks in a cloned voice (GPT-SoVITS), and has long-term memory, web search, screen understanding, and Twitch/Discord input. Windows only.
